# SENTINEL-S3 BLE - Blocos de Comando (CONTEXT LOCK + Fases A-E)

Regra: um bloco por turno. Se a IA nao viu o BLE master, manda o CONTEXT LOCK
uma vez. NimBLE only. A plataforma (PMU/tela/SD/PIN/ARM/allowlist/thermal/HID
mutex) TEM de existir antes. Build tem de passar. Escreve BLE_PHASE_x_STATUS.md
e PARA. Se quebrar, manda FIX, nao a fase seguinte.

### BLE-PHASE A  (scan + parser + vendor chips + UI)

```
Execute BLE-PHASE A now. NimBLE only. Legacy+extended scan, AD parser, vendor chips, UI list+detail. No HID, no spam TX. Write BLE_PHASE_A_STATUS.md.

GOAL
Bring BLE up on NimBLE and produce a live, deduplicated device inventory with vendor
classification. RX only. Nothing transmits except the controller's mandatory scan reqs.

STACK / KCONFIG
- NimBLE host, controller enabled, EXT_ADV=y, observer+central+peripheral roles.
- CONFIG_ESP_COEX_SW_COEXIST_ENABLE=y (Wi-Fi may be up).
- Host task on its own FreeRTOS task; never block LVGL.

IMPLEMENT
  ble/ble_stack.c/.h      # nimble init, host task, sync cb, coex on, thermal-aware
  ble/ble_scan.c/.h       # legacy + extended scan; report primary/secondary PHY
  ble/ble_ad_parser.c/.h  # truncation-proof AD walker (never read past AD length)
  ble/ble_vendor.c/.h     # classify: Apple Continuity(type table)/AirPods/FindMy,
                          # Swift Pair(0x0006), Fast Pair(0xFE2C), Eddystone(0xFEAA),
                          # iBeacon, Samsung(0x0075), Tile(0xFEED/0x0157), Xiaomi(0xFE95),
                          # Espressif BluFi(0xFFFF), Improv(0x4677), Flipper(name+sig),
                          # Mesh(0x1827/0x1828), HID(0x1812), NUS(128-bit)
  ble/ble_inventory.c/.h  # ble_device_t table, dedup by addr (flag RPA/random-static)
  ui: BLE list (name/addr/rssi/vendor/PHY) + detail (AD raw, svc UUIDs, cont_type, flags)

RULES
- Truncation-proof: every AD field bounded by its length byte.
- Mark address kind: public / random-static / RPA (Privacy 1.2).
- No connect, no advertise, no HID in this phase.

DONE
Inventory populates from real air; vendors classified; UI list+detail work.
Write BLE_PHASE_A_STATUS.md (OK/FAIL per item, build log).
```
